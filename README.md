# Guardian Safety App

## Overview
The Guardian Safety App is a Command Line Interface (CLI) software written in Kotlin. It is designed to help parents monitor their child's digital and physical well-being. The app simulates a dashboard where parents can view recent text messages, call logs, screen time, GPS location, and environmental sensor readings. It also includes a danger alert system that notifies the parent if the child is in a risky environment.
